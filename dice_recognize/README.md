# OpenCV サイコロ出目認識

黒い背景上の「白いサイコロ・黒い点」を認識するPythonアプリです。画像、動画、Webカメラに対応しています。

## セットアップ

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 起動

```bash
python app.py
```

画面上部から入力を選択します。認識したサイコロには緑の枠、各点にはオレンジの円が描かれ、出目、信頼度、検出数、合計が表示されます。

画面右側の「検出パラメータ」では、サイコロの面積範囲・縦横比・四角形らしさ・輪郭の充実度と、黒点の面積範囲・円形度を調整できます。静止画像ではスライダーを動かすと即座に再検出されます。「初期値に戻す」で標準設定へ戻せます。

背景の反射が白領域として抽出される場合は、「白領域しきい値を自動決定」をオフにして「明るさしきい値」を調整します。値を上げるほど、より明るい部分だけがサイコロ候補になります。「二値化マスクを表示」をオンにすると、候補として抽出されている場所を白黒で確認できます。

動作確認用画像は次のコマンドで生成できます。

```bash
python generate_demo.py
```

生成された `demo_dice.png` をGUIの「画像を開く」で選択してください。

## テスト

```bash
python -m unittest -v
```

## 認識しやすくする条件

- つやや影が少なく、背景との境界が明瞭な照明にする
- サイコロ同士を接触させない
- サイコロ全体がフレーム内に入り、1辺が20px以上になる距離にする
- 背景に白い物体を置かない

検出処理は、白領域からサイコロ候補を抽出し、回転を補正して正方形へ変換した後、黒い円形領域を数えています。

# サイコロ認識の実機確認

通常の自動テストは保存画像とフェイクカメラだけで実行する。この文書の操作はUSBカメラを接続したMacで、ユーザー立ち会いのもと実施する。

## 実施前

1. macOSの「プライバシーとセキュリティ > カメラ」で、使用するターミナルまたはアプリへカメラ権限を許可する。
2. USBカメラを接続し、他のアプリが使用していないことを確認する。
3. 黒く反射の少ない背景、白いサイコロ、影や映り込みの少ない照明を用意する。
4. `nvm use` でNode 22、`.venv` でPython 3.13の環境を選ぶ。

## 確認項目

- カメラを列挙し、対象デバイスIDを選択できる。
- 接続後にフレームを継続取得できる。
- ROIがサイコロを振る領域だけを含み、保存後の再起動でも同じ比率で復元される。
- 「振る → 静止 → 候補 → 一度だけ確定 → 除去待ち → 次を受付」の順に遷移する。
- 同じサイコロを置いたままにしても二度確定しない。
- サイコロの除去、または明確な再移動で次の受付へ進む。
- 低信頼度では自動確定せず、管理者が承認または1〜6へ修正できる。
- USBケーブルを抜くと切断状態になり、再接続後は待機状態から安全に再開する。
- 認識タイムアウト後に手動入力できる。

## 記録する評価値

- 正解した投擲数 / 全投擲数（認識率）
- 誤った値を確定した数 / 確定数（誤確定率）
- 投擲開始から確定までの時間
- 照明、カメラ角度、距離、背景、使用したしきい値

映像や画像を通常ログへ含めない。評価用に保存する場合は、通常ログと分離した明示的な保存先を使い、参加者が映り込まない画角と研究計画に沿った削除・アクセス管理を確認する。

## 保存映像の評価

映像と同じ時間軸の正解ラベルをJSONで用意する。時刻は秒で、投擲区間同士を重複させない。

```json
{
  "rolls": [
    {
      "id": "roll-001",
      "expectedValue": 4,
      "startSeconds": 1.2,
      "endSeconds": 3.8
    }
  ]
}
```

次のコマンドで評価し、標準出力または `--output` でJSONレポートを得る。

```bash
.venv/bin/python -m commentator.services.vision.evaluation \
  study-video.mp4 study-video.labels.json \
  --settings var/vision-settings.json \
  --output var/evaluations/study-video.report.json
```

`--settings`は省略できる。指定した場合は保存済みROIを映像にも適用する。

レポートには次を含む。

- 正しい自動確定または確認候補があった投擲の割合（認識率）
- 誤った自動確定と投擲区間外の自動確定の割合（誤確定率）
- 投擲開始から最初の正しい判断までの平均・中央値・95パーセンタイル
- 投擲ごとの正誤、確認待ちの有無、確定時間
- 判断ごとの総合信頼度と4つの内訳

評価ツールは映像を読み取るだけで、映像やフレームを通常ログまたはレポートへ埋め込まない。

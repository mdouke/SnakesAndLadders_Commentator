# ADR 0003: ID、時刻、APIエラー、構造化ログ

- 状態: Accepted
- 決定日: 2026-11-13

## 決定

- 新規エンティティIDはUUID v4、決定的なターン・操作イベントIDはUUID v5とする。
- HTTP要求ごとにサーバーがUUID v4のrequest IDを生成し、`X-Request-ID`、エラー本文、ログで共有する。
- 永続化、API、ログの時刻はtimezone-awareなUTCのISO 8601（`+00:00`）とし、表示時だけUIでローカル時刻へ変換する。経過時間は単調増加時計で測る。
- APIエラーは `detail: { code, message, context, requestId }` に統一する。`code` はsnake_caseの機械判定値、`message` は日本語表示、`context` は安全な補足情報とする。
- アプリケーションログは1行1 JSONでstdoutへ出す。外部ログサービスは初期版に含めない。
- APIキー、Authorization、音声本文、プロンプト全文、カメラ画像、プレイヤーの読み方はログへ出さない。

## ローカルログ

- 既定の `rotate` は30日を超えたログを起動時に削除し、1ファイル10MB、5世代でサイズローテーションする。
- `permanent` は日単位でファイルを分け、アプリケーションから削除しない。
- 日数、サイズ、世代数は環境変数で変更できる。
- `permanent` でも機微情報を記録しない規約は変わらない。ディスク使用量の監視と研究データの管理責任は運用者が負う。

## 対象範囲

初期版はmacOS上の単一PC・1 APIワーカーを対象とする。分散トレーシングや外部ログ収集は、複数プロセス・複数端末が必要になった時点で別ADRにする。
